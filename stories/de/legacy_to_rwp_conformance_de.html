RecordWeb · Von der Legacy-Anwendung zur RWP-Konformität

Fünf Bausteine machen aus einer bestehenden Anwendung eine RWP-konforme Anwendung.

Jeder Block hängt vom vorhergehenden ab. Der Resolver kann je nach Architektur der Organisation als gemeinsam genutzte Infrastruktur oder als integrierter Bestandteil vorliegen.

1 Gemeinsame Infrastruktur Namespace registration

Registrieren Sie einen Namensraum (namespace) entweder über die zuständige Behörde Ihres Landes oder über die Registrierungs-App der RecordWeb Trust Association. Sie geben Ihre Endpunkt-URL ein und erhalten im Gegenzug einen Namensraum.

// Global Namespace Registry { "namespace": "8f3a", "resolverEndpoint": "https://vps.recordweb.dev/…" }
2 Anwendungsspezifisch SchemaRecord

Definiert die Struktur für einen Datensatztyp als eigenen, versionierten und referenzierbaren Datensatz, noch bevor ein tatsächlicher Datensatz dieses Typs erstellt werden kann.

{ "did": "did:rwp:8f3a:report-v1", "recordType": "SchemaRecord", "title": "Report", "version": "1.0.0" }
3 Anwendungsspezifisch IMS / DMS / RMS

Erstellt Datensätze, die auf den SchemaRecord verweisen, enthält die erforderlichen Kern-, Governance- und (optional) Erweiterungsmetadaten und verwaltet den Lebenszyklus vom Entwurf bis zur Fertigstellung.

{ "did": "did:rwp:8f3a:9d21", "payload": [ /* 1 finalized snapshot */ ], "metadata": { "core": { "recordType": "did:rwp:8f3a:report-v1", "schemaVersion": "sha256:a665a4…" }, "governance": { "owner": "did:rwp:met-office", "classification": "public", "tags": ["weather", "2026-08-25"] }, "extensions": [ { "type": "did:…:geo-station-ref", "stationId": "CH-BE-014" } ] }, "recordHash": "sha256:9f8e7d…" }
4 Anwendungsspezifisch Auslieferungs API

Stellt den Datensatz und seine Metadaten über HTTP unter einer festen URL bereit, genau auf diese Adresse verweist der Eintrag recordEndpoint im DID-Dokument. Vergessen Sie nicht, Zugriffskontrollen und weitere Massnahmen zu implementieren; dies wird von RWP nicht abgedeckt.

// GET https://vps.recordweb.dev/records/ did%3Arwp%3A8f3a%3A9d21 // → 200 OK, application/json // → returns the record shown left
5 Gemeinsame Infrastruktur Resolver Verbindung

Der Endpunkt der Anwendung wird in das vom Resolver verwaltete DID-Dokument geschrieben (sofern keine Integration vorliegt).

{ "id": "did:rwp:8f3a:9d21", "recordEndpoint": "https://vps.recordweb.dev/…" }
