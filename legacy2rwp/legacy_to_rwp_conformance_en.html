RecordWeb · From legacy application to RWP conformance

Five building blocks turn an existing application into an RWP-conformant one.

Each block depends on the one before it. The Resolver may be shared infrastructure or integrated, depending on organizatinos architecture.

1 Shared infrastructure Namespace registration

Register a namespace either through your country's national authority, or self-service through the RecordWeb Trust Association's registration app. You submit your endpoint URL and receive a namespace in return.

// Global Namespace Registry { "namespace": "8f3a", "resolverEndpoint": "https://vps.recordweb.dev/…" }
2 Application builds this SchemaRecord

Defines the shape for one record type as its own versioned, referenceable record — before any actual record of that type can be created.

{ "did": "did:rwp:8f3a:report-v1", "recordType": "SchemaRecord", "title": "Report", "version": "1.0.0" }
3 Application builds this IMS / DMS / RMS

Creates records that reference the SchemaRecord, carries the required core, governance and (optionally) extension metadata, and manages the draft → finalized lifecycle.

{ "did": "did:rwp:8f3a:9d21", "payload": [ /* 1 finalized snapshot */ ], "metadata": { "core": { "recordType": "did:rwp:8f3a:report-v1", "schemaVersion": "sha256:a665a4…" }, "governance": { "owner": "did:rwp:met-office", "classification": "public", "tags": ["weather", "2026-08-25"] }, "extensions": [ { "type": "did:…:geo-station-ref", "stationId": "CH-BE-014" } ] }, "recordHash": "sha256:9f8e7d…" }
4 Application builds this Delivery API

Serves the record and its metadata over HTTP at a stable URL — this is exactly the address that recordEndpoint in the DID document will point to. Don't forget to implement access control and more, this is not covered by RWP.

// GET https://vps.recordweb.dev/records/ did%3Arwp%3A8f3a%3A9d21 // → 200 OK, application/json // → returns the record shown left
5 Shared infrastructure Resolver linkage

The application's endpoint is written into the DID document maintained by the Resolver (if not integrated).

{ "id": "did:rwp:8f3a:9d21", "recordEndpoint": "https://vps.recordweb.dev/…" }
